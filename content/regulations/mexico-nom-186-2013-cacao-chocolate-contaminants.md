<section id="reginteraction" style="margin-bottom:20px"><h2 style="font-family:Lora,serif;font-weight:400;font-size:30px;line-height:1.2;color:#2b1f1f;border-bottom:1px solid #e8e1db;padding-bottom:10px;margin:0 0 20px">How this interacts with HMTc</h2><p style="font-size:16.5px;line-height:1.78;color:#3f3a3a;margin:0 0 18px;max-width:72ch">HMTc certification standards adopt the <em>strictest existing</em> maximum level set by any credible government, applied cell-by-cell. Where this instrument holds the strictest value for a (product, analyte) cell, it binds the HMTc limit and the standard cites this page. This page does not set or justify any HMTc threshold; it records the sovereign requirement the program measures against.</p><div style="border-left:3px solid #9f2727;background:#fdf4f3;padding:18px 22px"><p style="font-size:15.5px;line-height:1.75;color:#5a4141;margin:0">A reference page is a record of law, not an HMTc threshold. It states what a government requires; the standard page states what the program requires, and names which instrument binds each cell.</p></div></section>
