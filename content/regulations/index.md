<section id="what" style="margin-bottom:52px"><h2 style="font-family:Lora,serif;font-weight:400;font-size:30px;line-height:1.2;color:#2b1f1f;border-bottom:1px solid #e8e1db;padding-bottom:10px;margin:0 0 20px">What this collection records</h2><p style="font-size:16.5px;line-height:1.78;color:#3f3a3a;margin:0 0 18px;max-width:72ch">An HMTc standard adopts the strictest existing maximum level set by any credible government, applied cell-by-cell. That claim is only checkable if the underlying government values are published in one place, in the basis each instrument states, with the provision that carries them. These pages are that place.</p><p style="font-size:16.5px;line-height:1.78;color:#3f3a3a;margin:0 0 18px;max-width:72ch">39 instruments are tracked, spanning national and supranational food-contaminant law across every product matrix. 5 are currently cited by a published HMTc standard; the rest are recorded for register completeness, available as the program expands to new categories and jurisdictions. California Proposition 65 lists several of the eight metals as hazards but, as a right-to-know warning statute, sets no maximum level in food, and is recorded <a href="/regulations/ca-prop65" style="color:#1c43ad;text-decoration:none">for that gap alone</a>.</p><div style="border-left:3px solid #9f2727;background:#fdf4f3;padding:18px 22px"><p style="font-size:15.5px;line-height:1.75;color:#5a4141;margin:0">A reference page is a record of law, not an HMTc threshold. It states what a government requires; the standard page states what the program requires, and names which of these instruments binds each cell.</p></div></section>
