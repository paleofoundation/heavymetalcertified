<section id="basis" style="margin-bottom:44px"><h2 style="font-family:Lora,serif;font-weight:400;font-size:30px;line-height:1.2;color:#2b1f1f;border-bottom:1px solid #e8e1db;padding-bottom:10px;margin:0 0 20px">Basis and method notes</h2><p style="font-size:15.5px;line-height:1.75;color:#3f3a3a;margin:0 0 16px;max-width:84ch">Values are recorded in the native basis each row states (for example whole commodity, as consumed, muscle meat, or as placed on the market). A limit in one basis is not directly comparable to a limit in another without conversion.</p></section>
<section id="hmtc" style="margin-bottom:44px"><h2 style="font-family:Lora,serif;font-weight:400;font-size:30px;line-height:1.2;color:#2b1f1f;border-bottom:1px solid #e8e1db;padding-bottom:10px;margin:0 0 20px">How this interacts with HMTc</h2><p style="font-size:15.5px;line-height:1.75;color:#3f3a3a;margin:0;max-width:84ch">HMTc certification standards adopt the <em>strictest existing</em> maximum level set by any credible government worldwide. Where this instrument holds the strictest value for a (product, analyte) cell, it binds the HMTc limit and the standard cites this page. This page does not set or justify any HMTc threshold; it records the sovereign requirement the program measures against.</p></section>
