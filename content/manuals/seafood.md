<section style="margin-bottom:44px"><h1 style="font-family:Lora,serif;font-weight:400;font-size:34px;line-height:1.15;color:#2b1f1f;margin:0 0 14px">Seafood — HMTc Program Manual</h1>
<p style="font-size:16px;line-height:1.7;color:#3f3a3a;max-width:80ch;margin:0 0 14px">The complete Heavy Metal Tested &amp; Certified standard for Category&nbsp;6, Seafood, edition 2026. Every limit on every subcategory is the strictest maximum level set by any credible government worldwide, converted to the product&rsquo;s native basis, with a disclosed read-across from the nearest government value where no government regulates the exact product. Nothing is invented; every number traces to a named sovereign limit in the <a href="/regulations" style="color:#1c43ad;text-decoration:none">regulation references</a>.</p>
<p style="font-size:13.5px;line-height:1.7;color:#736b6b;max-width:80ch;margin:0">Method: <a href="/program/structure" style="color:#1c43ad;text-decoration:none">government-limit default (Method v2.0)</a>. Seafood limits are taken at face value in each product&rsquo;s native basis; there is no reconstitution conversion. Mercury is limited in both forms &mdash; total mercury (Hg) and methylmercury (MeHg) are separate ceilings, set to the species-specific tier each government assigns (predatory fish carry the higher ceiling, lower-trophic species the lower). Tier&nbsp;1 toxics (Pb, Cd, iAs, Hg) are zero-tolerance; Tier&nbsp;2 (tAs, Sn) carry the program&rsquo;s 150% transitional allowance. Total arsenic operates as a reflex screen to inorganic-arsenic speciation. Tin is material only for canned product, where it migrates from the can; for non-canned seafood it is controlled by screen, not assigned an invented number.</p></section>
