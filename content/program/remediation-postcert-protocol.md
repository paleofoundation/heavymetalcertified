  <p style="font-size:15px;line-height:1.75;color:#5a4141;margin:0 0 12px;max-width:74ch">This is the alternative to <a href="/program/remediation" style="color:#1c43ad">the live pre-certification page</a>. It describes a proposed <span style="color:#9f2727">post-certification</span> voluntary-disclosure protocol: a mechanism under which a brand that already holds a certificate may self-report a finding, choose confidential or public handling, and keep its certificate and mark while the item is open and on schedule.</p>
  <p style="font-size:15px;line-height:1.75;color:#5a4141;margin:0;max-width:74ch">No such protocol is ratified today. Program Manual Part&nbsp;2.4 defines the Confidential Remediation Track as an entry pathway for products that are <span style="color:#9f2727">not yet certifiable</span>, and states in terms that it is &ldquo;not a post-certification mechanism.&rdquo; Publishing this page would make a public promise that no ratified rule supports. It is held at <span style="font-family:'IBM Plex Mono',monospace;font-size:13px;color:#9f2727">draft:true</span> so the build excludes it. Before it can ship, a governing section must be ratified and its number written into every place this page marks <span style="font-family:'IBM Plex Mono',monospace;font-size:13px;color:#9f2727">§&nbsp;proposed</span>.</p>
</div>

<section id="why" style="margin-bottom:52px">
  <h2 style="font-family:Lora,serif;font-weight:400;font-size:30px;line-height:1.2;color:#2b1f1f;border-bottom:1px solid #e8e1db;padding-bottom:10px;margin:0 0 20px">Why it would exist</h2>
  <p style="font-size:16.5px;line-height:1.78;color:#3f3a3a;margin:0 0 18px;max-width:72ch">Every certification program faces the same problem after it issues a certificate. The moment a finding becomes a public event, the rational move for a certified brand is to stop looking &mdash; test less often, test fewer lots, avoid asking questions whose answers create disclosure obligations. A program that punishes discovery gets less discovery, and the mark it issues becomes a statement about how little a brand knows.</p>
  <p style="font-size:16.5px;line-height:1.78;color:#3f3a3a;margin:0 0 18px;max-width:72ch">A post-certification track would be the answer to that. A certified brand that identifies a problem and reports it would enter a defined, confidential process with its certificate intact <span style="font-family:'IBM Plex Mono',monospace;font-size:12.5px;color:#9f2727">[§ proposed]</span>. The corrective action would not be reduced, the re-testing would not be reduced, and the deadline would be real &mdash; but the finding would not become a press cycle for having been honest.</p>
  <div style="border-left:3px solid #9f2727;background:#fdf4f3;padding:18px 22px">
    <p style="font-size:15.5px;line-height:1.75;color:#5a4141;margin:0">The asymmetry is deliberate and it is the whole mechanism: self-reporting is cheaper than concealment. Concealment of a known exceedance is grounds for revocation, which is the most severe outcome the program has &mdash; and this part is ratified today (Part&nbsp;2.2).</p>
  </div>
</section>

<section id="ratify">
  <h2 style="font-family:Lora,serif;font-weight:400;font-size:30px;line-height:1.2;color:#2b1f1f;border-bottom:1px solid #e8e1db;padding-bottom:10px;margin:0 0 20px">What ratification would require</h2>
  <p style="font-size:16.5px;line-height:1.78;color:#3f3a3a;margin:0 0 18px;max-width:72ch">To move this page from draft to live, a post-certification voluntary-disclosure protocol must be added to the Program Manual (a new Part&nbsp;2 section) or the Governance Policy, and every marker reading <span style="font-family:'IBM Plex Mono',monospace;font-size:12.5px;color:#9f2727">[§ proposed]</span> above must be replaced with its real section number. The protocol has to state, at minimum: the conditions under which a certified product&rsquo;s status is held rather than escalated during an open item; the maximum on-schedule window; the Tier&nbsp;1 boundary; and the interaction with the public register and the mark. Until that exists, the live page is the pre-certification one, and this file stays <span style="font-family:'IBM Plex Mono',monospace;font-size:12.5px;color:#9f2727">draft:true</span>.</p>
