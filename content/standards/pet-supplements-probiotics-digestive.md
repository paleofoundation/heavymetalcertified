<section id="method" style="margin-bottom:52px"><h2 style="font-family:Lora,serif;font-weight:400;font-size:30px;line-height:1.2;color:#2b1f1f;border-bottom:1px solid #e8e1db;padding-bottom:10px;margin:0 0 20px">How limits are set</h2><p style="font-size:15.5px;line-height:1.75;color:#3f3a3a;margin:0 0 16px;max-width:84ch">Why the anchor family is child-protective rather than adult-supplement. The nearest same-form sovereign analog for a pet supplement is a human food supplement, and several governments do set maxima for those. HMTc does not use them, for the same reason Category 16 does not: they are an adult-intake framework, they run one to three orders of magnitude above the child-food ceilings, and a companion animal is a small-bodied consumer receiving a concentrated dose.</p><p style="font-size:15.5px;line-height:1.75;color:#3f3a3a;margin:0 0 16px;max-width:84ch">A four-kilogram cat given a one-gram daily supplement scoop, or a five-kilogram dog given a soft chew, sits in a body-weight-normalised intake range comparable to an infant on formula and far above a seventy-kilogram adult.</p><p style="font-size:15.5px;line-height:1.75;color:#3f3a3a;margin:0 0 16px;max-width:84ch">That is the disclosed rationale for which analog family HMTc adopts; it is not a calculation and it does not select any number. Every number still comes from a named sovereign instrument in the register, and the instrument, the limb of the instrument, and the floors HMTc declined are all named on the cell.</p><p style="font-size:15.5px;line-height:1.75;color:#3f3a3a;margin:0 0 16px;max-width:84ch">Why the numbers differ from HMTc Category 16 in four cells. Category 16 anchors cadmium, inorganic arsenic, nickel and total mercury on the liquid or ready-to-eat limb of form-split instruments and applies those values to as-sold solid supplements. Category 18 takes the powder limb of the same instruments, because the product is an as-sold concentrate and Method v2.0 step 4 requires preserving the product-form split the government rule itself writes.</p><p style="font-size:15.5px;line-height:1.75;color:#3f3a3a;margin:0 0 16px;max-width:84ch">Category 18 is therefore not laxer as a matter of policy; it is the same instrument family read in the correct limb, and the difference is recorded here rather than smoothed over.</p><p style="font-size:15.5px;line-height:1.75;color:#3f3a3a;margin:0 0 16px;max-width:84ch">The two applicability filters, in order. The first is mechanical: only register rows the register itself classifies basis_class=as_sold may anchor a cell, which blocks every reconstituted and feed-basis row without any judgment being exercised. The second is declared and uniform: the anchor must come from the adopted analog family, which is finished foods intended for a small consumer.</p><p style="font-size:15.5px;line-height:1.75;color:#3f3a3a;margin:0 0 16px;max-width:84ch">The second filter is needed because basis_class records whether a limit is written on the product as sold, not how much water the commodity contains, so a fresh-vegetable or fluid-milk ceiling can pass the mechanical filter and still be looser than it looks against an as-sold dry concentrate.</p><p style="font-size:15.5px;line-height:1.75;color:#3f3a3a;margin:0 0 16px;max-width:84ch">The widened stricter-unselected audit scan is pointed at exactly those commodity families so that every such row surfaces in the derivation report with its disposition attached, rather than being quietly out of scope.</p><p style="font-size:15.5px;line-height:1.75;color:#3f3a3a;margin:0 0 16px;max-width:84ch">The complete set of rows it surfaces across all seven subcategories is hk_cap132v_thg_vegetables-other-than-edible-fungi_10, hk_cap132v_thg_milk_10, hk_cap132v_thg_secondary-milk-products_10, il_fcs2016_thg_1_milk_10, il_fcs2016_cd_1_milk_5 and il_fcs2016_ias_1_milk_10; every one is a wet whole-commodity ceiling for fresh vegetables or fluid milk, none is adopted, and the disposition is recorded on each affected cell as well as here.</p><p style="font-size:15.5px;line-height:1.75;color:#3f3a3a;margin:0 0 16px;max-width:84ch">An independent sweep of every live row in the widened credible set that the register classifies as_sold, run without this compiler's scope regex and without its infant-row exclusion, returns no other row stricter than any binding in this category.</p><p style="font-size:15.5px;line-height:1.75;color:#3f3a3a;margin:0 0 16px;max-width:84ch">Why all seven rows carry the same numbers. The adopted anchor family is a finished-child-food ceiling, which is defined by the consumer and the basis rather than by the ingredient, so it does not vary between a vitamin powder and a botanical blend. Category 16 publishes the same uniform shape for the same reason.</p><p style="font-size:15.5px;line-height:1.75;color:#3f3a3a;margin:0 0 16px;max-width:84ch">The rows differ where the evidence actually differs: in the methylmercury posture (every-lot speciation where marine or freshwater material is routine, reflex speciation otherwise), in the hexavalent-chromium posture (every-lot speciation trigger where mineral, clay or geologic carriers are declared, and a lead-and-chromium co-elevation adulteration trigger on the botanical row), in the total-chromium rationale (chromium is a declared nutrient in the vitamin and mineral row and a contaminant everywhere else), and in the tin escalation rule.</p><p style="font-size:15.5px;line-height:1.75;color:#3f3a3a;margin:0 0 16px;max-width:84ch">Occurrence history is recorded in the scope notes because it drives sampling posture; it never moves a ceiling.</p></section>
