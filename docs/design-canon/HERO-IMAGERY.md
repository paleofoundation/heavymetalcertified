# Subject-matched Heavy Metal Index imagery

Presentation registry: `quartz/components/categoryHeroImages.ts`.
Source: `paleofoundation/heavymetalindex`, `quartz/static/heroes/README.md`
and `data/design/metal-hero-images.json`, inspected 2026-10-16.
Public originals: `https://heavymetalindex.com/static/heroes/<filename>`.
Locally vendored, original image bytes retained. No hotlink dependency.

These are AI-generated conceptual editorial still lifes from the Index, not photographs
of tested or contaminated samples. No people, labels, warnings or text in the images.
The left-hand dark field supports real HTML copy. Images are decorative (empty alt),
so they do not add a claim or change structured data, descriptions or social metadata.

The registry uses explicit slug matches, including rice, grains, seafood, shellfish,
nuts, legumes, chocolate, tea, food-contact goods and the eight analytes. A rice grain
image is ingredient context for rice-derived foods, never a depiction of their packaging.

Missing exact subjects remain plain navy. In particular, the source registry currently
contains no infant formula, fruit puree, root puree or non-root puree asset. The Infant
and Child Foods manual spans all of these and therefore gets no misleading single-food
fallback. Dairy, cosmetics, fungi, toys and the other unmatched manuals also remain navy.
An exact source image can later be added to the same allowlist without editing content.
No new images were generated and no unrelated generic image is assigned to these gaps.

Manual cover images and author identity text remain as authored. The compact hero author
portrait is presented as a profile-link icon so the hero has no people imagery; its existing
accessible link and author popover are retained. New hero imagery has no baked-in text.
