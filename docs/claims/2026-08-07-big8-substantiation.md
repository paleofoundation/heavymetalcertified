# Substantiation record — "The only food certification with a published limit for all eight metals"

**Date of research:** 2026-08-07
**Claim placed on homepage hero:** "The Big 8 — we set the gate." / "The only food certification with a published limit for all eight metals — including the aluminium no other certification limits."
**Purpose:** FTC §5 reasonable-basis file for the "only / all eight" advertising claim. Retain and re-date on material change.

## The eight metals ("Big 8")
Lead (Pb), arsenic (As), mercury (Hg), cadmium (Cd), chromium (Cr), nickel (Ni), tin (Sn), aluminium (Al).

## Method
Adversarial search for any existing third-party certification/seal program that sets published limits against all eight. A single counterexample refutes the claim. HMTc / heavymetalcertified.com (the claimant's own program) was excluded as self-referential.

## Comparable programs — none cover all eight
| Program | Metals covered | Ni/Sn/Al/Cr? | Cert seal? |
|---|---|---|---|
| Clean Label Project (Certified + Purity Award) | Pb, As, Cd, Hg (big four) | none | yes |
| USP Verified (USP <2232>) | Pb, As, Cd, Hg | none | yes |
| NSF/ANSI 173 + Certified for Sport | Pb, As, Cd, Hg + **Cr(VI)** (five) | Cr only | yes |
| Informed Sport / Informed Choice | As, Pb, Cd, Hg (screen) | none | batch cert |
| Made Safe | "heavy metals" ban-category, not enumerated | n/a | yes (not food-numeric) |
| EWG Verified | restricted-ingredient bans | no | not a food-metals program |
| Low Heavy Metals Verified | Pb, Cd, As, Hg | none (Al/Ni/Sn "future") | self-cert, not licensed |
| Consumer Reports / ConsumerLab / Labdoor | vary (mostly big four) | vary | **publications/labs, not certifiers** |
| ICH Q3D / USP <232> (pharma) | 24 elements incl **7 of 8** (As,Cd,Pb,Hg,Ni,Cr,Sn) | Ni/Cr/Sn yes; **Al excluded** | **pharmacopeial drug standard, not a food seal** |
| Expanded clinical panels (Doctor's Data etc.) | 20+ incl Al/Sn/Ni/Cr | yes | **lab service, not a cert against a standard** |

**Universal gap = aluminium.** No food or supplement certification sets an aluminium action level; even ICH Q3D (24 elements, the broadest elemental-impurity standard) deliberately excludes it. This is the strongest, most independently verifiable differentiator.

## Verdict
- No third-party certification **seal** covers all eight (confidence: high). Nearest miss ICH Q3D reaches seven but excludes aluminium and is a pharmaceutical standard, not a food certification.
- **Defensible:** "the only food certification with a published limit for all eight" (scoped to *food certification with published limits* — excludes the pharma near-miss and the ban-list/lab programs).
- **Do NOT use, as written:** "world's first to regulate the Big 8." "World's" = unprovable global negative; "regulate" implies government authority (certifier sets voluntary limits). "First beyond the big four" is false (NSF already adds Cr-VI).

## Wording guardrails (applied to the live claim)
1. Scope to "food certification," never "world's."
2. "sets a published limit for" / "the only … covering" — never "regulates."
3. Keep the explicit eight-metal list adjacent to the claim.
4. Add "currently" + this date if programs evolve (Low Heavy Metals Verified signals it may add Al/Ni/Sn).
5. Retain this dated file as the reasonable-basis record.
