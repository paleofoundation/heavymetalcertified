## Sub-panel headers (86)

Each page whose Master Limit Table shows "N of 11 analytes with a published limit" (N<8) is the same set of blockers surfaced as a header, not a separate gap. A header rises to 8/8 only when its blocking cells above are resolved — which, per the above, requires a governance ruling or new sovereign law, never a fabricated number.

## What would move these

1. **New sovereign law** — a credible regulator (EU/UK/Codex/US/CA/AU-NZ/HK) issues a total-basis ML for the matrix. The ratchet then tightens automatically on recompile.
2. **A dated Karen governance ruling** admitting a jurisdiction currently outside the credible set (precedent: HK Cap 132V admitted 2026-08-17). See the governance-unlockable inventory in docs/S-DOI-1-CLAIM-CELL-BLOCKERS.md §A — note admitting to fill a cell frequently *loosens* the standard.
3. Nothing else. In particular, occurrence data, percentiles, and analogous non-credible caps are not eligible anchors.
